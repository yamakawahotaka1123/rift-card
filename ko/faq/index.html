자주 묻는 질문

서머너 카드가 뭔가요?
리그 오브 레전드 플레이어가 랭크・포지션・주력 챔피언・플레이 시간 등을 정리한 자기소개 이미지예요. X나 디스코드 서버의 자기소개 채널에서 듀오나 친구를 구할 때 많이 써요.
무료인가요? 가입해야 하나요?
완전 무료이고, 회원가입이나 로그인도 필요 없어요.
휴대폰으로도 만들 수 있나요?
휴대폰 브라우저에서 바로 만들 수 있어요. 아이폰에서는 「이미지 저장」을 누르면 카드가 크게 표시되니까, 길게 눌러서 사진에 저장해 주세요.
X 앱에서 열면 저장이 안 돼요
X・인스타그램・카카오톡 같은 앱 내 브라우저에서는 이미지 저장이나 공유가 제한될 때가 있어요. 오른쪽 위 「…」에서 「브라우저로 열기」를 선택해 Safari나 Chrome으로 열어 주세요. 앱 내 브라우저 그대로도 표시된 이미지를 길게 누르면 저장할 수 있어요.
템플릿 이미지를 편집해야 하나요?
아니요. 이미지 편집 앱은 필요 없어요. 항목을 입력하고 테마를 고르기만 하면 챔피언과 랭크 아이콘이 들어간 카드가 자동으로 완성돼요.
소환사 이름을 공개하고 싶지 않으면요?
소환사 이름 칸 아래에 있는 「비공개」「같이 할 때 알려드려요」「DM으로 알려드려요」「친해지면 알려드려요」 문구를 고를 수 있어요.
랭크는 자동으로 불러오나요?
지금은 직접 선택하는 방식이에요. 언랭크이거나 랭크를 공개하고 싶지 않은 분도 그대로 쓸 수 있어요.
입력한 내용이 어딘가로 전송되나요?
입력 내용과 업로드한 이미지는 사용 중인 브라우저 안에서만 처리・저장되고 운영자 서버로는 전송되지 않아요.
나중에 수정할 수 있나요?
입력 내용은 브라우저에 자동 저장되니까 다음에 열어도 이어서 수정할 수 있어요. 브라우저 데이터를 지우거나 다른 기기・다른 브라우저로 열면 이어지지 않아요.
만든 이미지를 자유롭게 써도 되나요?
X, 디스코드, 방송 화면, 트위치 패널 등에 자유롭게 쓸 수 있어요. 만든 이미지나 그 안의 롤 소재를 판매하는 것은 안 돼요. 자세한 내용은 이용약관을 확인해 주세요.
이미지 오른쪽 아래 URL을 지울 수 있나요?
디자인 항목 아래에 있는 「카드 오른쪽 아래에 사이트 URL 넣기」 체크를 해제하면 지워져요. 그대로 두시면 사이트가 널리 알려져서 정말 기뻐요.
